Revoke Key

Deactivate a license so the customer can re-activate on a new device

Revoke License

Revoking a key deactivates it immediately. The customer will need to re-enter their key to re-activate. Use this when a customer switches devices or clears their browser data.

When to Revoke

Always revoke for: Customer cleared browser data, switching to a new device, token expired after 1 year.

Use judgment for: Repeated device-switch requests from the same customer (possible key sharing).

Escalate to owner: Suspected key sharing or piracy.

Credit Back

Restore prompts or images for customers who experienced errors or failed generations

Credit Back Usage

Policy

Always grant for: Genuine technical errors, failed generations, server downtime that consumed credits.

Use judgment for: Requests for significantly more credits than the tier allows (offer upgrade first).

"We will always make exceptions. That just won't be the rule."

Quick Reference

Key facts, policies, and known issues for the license system

Standard Policies

PolicyDetails
Activations per keyOne device at a time. Revoke to switch.
Monthly usage resetResets on first request of the new month. No credit rollover.
Token lifetime365 days. Revoke and re-activate to renew.
Conversation storageNone. Core product promise. Never log prompts or responses.
Tier 1 + Command CenterNot allowed. Returns TIER_NO_ACCESS error with upgrade link.

Known Issues and Gotchas

JWT_SECRET rotation invalidates ALL tokens. If the JWT_SECRET env var is changed on Render, every customer's session becomes invalid. Only change if absolutely necessary.

Revoke required before re-activation. The system does not allow re-activating an already-activated key. Always revoke first.

Tier upgrade requires new token. After upgrading a key's tier via SQL, the customer must clear browser data and re-activate to get a new JWT with the correct tier.

Custom limits persist permanently. Once set, custom limits override tier defaults until cleared via direct SQL: SET custom_prompt_limit = NULL, custom_image_limit = NULL.

The notes field is your friend. Always add notes when making admin changes. This is your audit trail.
