Scoring Methodology

                
            

            

                Each pair uses the same foundation, host and generation
                settings. Only the OffGrid contestant receives the additional
                OffGrid instructions. Each question stands alone. Anonymous
                labels and generation order are shuffled; model identity can
                still be inferred from writing style.
            

            

                GPT-5.2 is the outside judge for every new comparison. An
                outside AI judge can still have biases and make mistakes.
                Incomplete answers or an invalid review produce no winner. No
                answer is rewritten. Historical Council results remain separate
                in analytics.
            

            

                Automatic categories use only the question, in a separate
                GPT-5.2 request before answer generation. A selected category
                overrides that step. Categories never enter answer or grading
                prompts. Classification failures are labeled General / Visual
                fallback, not counted as answer failures. Earlier records keep
                their original categories.
            

            

                E4B uses the pinned USB model artifact on a Linux GPU. The 26B
                pair uses hosted OpenRouter inference, not the USB quantized
                file. This measures conditioning within each pair, not overall
                offline runtime equivalence.
