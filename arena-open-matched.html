Grading Report

Scoring Methodology

Each pair uses the same foundation, host and generation settings. Only the OffGrid contestant receives the additional OffGrid instructions. Each question stands alone. Anonymous labels and generation order are shuffled; model identity can still be inferred from writing style.

GPT-5.2 is the outside judge. Council uses four peer-review calls, including duplicate foundation families; those votes are not independent experts. Incomplete answers or reviews produce no winner. No answer is rewritten.

E4B uses the pinned USB model artifact on a Linux GPU. The 26B pair uses hosted OpenRouter inference, not the USB quantized file. This measures conditioning within each pair, not overall offline runtime equivalence.
